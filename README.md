Vrinda Store Sales Analysis Dashboard
📌 Project Overview

This project presents a sales analysis dashboard for Vrinda Store, built using Excel/Power BI (as per your setup), to analyze customer behavior, sales trends, platform performance, and delivery outcomes.

The goal of this project is to convert raw sales data into meaningful business insights that can support decision-making.

🎯 Business Questions Answered

The dashboard answers the following key questions:

What is the total revenue and total number of orders?

Which age group contributes the most to sales?

How do sales vary month-wise?

Which online platforms generate the highest orders?

Which cities are top contributors?

What is the delivery success rate?

How do gender and product categories impact sales?

📈 Key Insights

Total Revenue: ₹2,11,76,377

Total Orders: 31,047

Top Customer Segment: Adult age group

Peak Sales Month: March

Top Platform: Amazon

Top Cities: Bengaluru, Hyderabad, New Delhi

Delivery Success: Majority of orders successfully delivered

Gender Insight: Women customers dominate sales, especially in Kurtas and Sets
